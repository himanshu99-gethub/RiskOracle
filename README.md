# 🛡️ RiskOracle: Quantum-Noir Predictive Observatory

RiskOracle is a high-end predictive analytics dashboard for loan risk assessment. It features a modern **Quantum-Noir** (Glassmorphic Dark Mode) UI and a robust **Flask** backend using a Logistic Regression model for real-time predictions.

## 🎯 Features
- **Quantum-Noir Interface:** Vibrant glassmorphic design with subtle micro-animations and smooth transitions.
- **Intelligent Risk Scoring:** Real-time prediction using a Logistic Regression engine.
- **Factor Analysis:** Live breakdown of Credit Stability, Collateral Coverage, and Market Volatility.
- **Portfolio Observatory:** Advanced statistical overview showing total applications, approval rates, and average applicant income.
- **Localized Standards:** Fully optimized for **Indian Rupee (₹)** financial metrics.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Backend:** Flask (Python).
- **Machine Learning:** Scikit-learn (Logistic Regression).
- **Data Handling:** Pandas, NumPy.

## 🚀 How to Run
1. Ensure you have Python installed.
2. Install dependencies:
   ```bash
   pip install flask pandas scikit-learn numpy
   ```
3. Start the application:
   ```bash
   python server.py
   ```
4. Access the dashboard at [http://127.0.0.1:5000](http://127.0.0.1:5000).
